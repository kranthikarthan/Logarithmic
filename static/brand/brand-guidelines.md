# Assertly Brand Guidelines

## 🎨 Brand Identity

### Logo
- **Primary Logo**: Test vial with checkmark in gradient blue
- **Usage**: Always maintain clear space around logo
- **Minimum Size**: 24px height for digital, 0.5" for print
- **Colors**: Blue gradient (#0ea5e9 to #0284c7)

### Brand Colors

#### Primary Colors
- **Assertly Blue**: `#0ea5e9` (Primary-500)
- **Assertly Blue Dark**: `#0284c7` (Primary-600)
- **Assertly Blue Light**: `#38bdf8` (Primary-400)

#### Secondary Colors
- **Success Green**: `#22c55e` (Success-500)
- **Warning Orange**: `#f59e0b` (Warning-500)
- **Error Red**: `#ef4444` (Error-500)

#### Neutral Colors
- **Text Primary**: `#0f172a` (Dark text)
- **Text Secondary**: `#475569` (Medium text)
- **Text Muted**: `#94a3b8` (Light text)
- **Background**: `#ffffff` (White)
- **Border**: `#e2e8f0` (Light border)

### Typography

#### Primary Font: Inter
- **Weights**: 300, 400, 500, 600, 700, 800
- **Usage**: Headings, body text, UI elements
- **Fallback**: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

#### Monospace Font: JetBrains Mono
- **Weights**: 400, 500
- **Usage**: Code, technical content
- **Fallback**: 'Fira Code', 'Monaco', 'Cascadia Code', monospace

### Usage Guidelines

#### Logo Usage
- ✅ Use on light backgrounds
- ✅ Maintain clear space (2x logo height)
- ✅ Use full color version when possible
- ❌ Don't stretch or distort
- ❌ Don't use on busy backgrounds
- ❌ Don't change colors without approval

#### Color Usage
- ✅ Use primary blue for CTAs and highlights
- ✅ Use success green for positive actions
- ✅ Use neutral grays for text hierarchy
- ❌ Don't use more than 3 colors in one design
- ❌ Don't use colors that clash with brand palette

#### Typography Usage
- ✅ Use Inter for all UI text
- ✅ Use JetBrains Mono for code
- ✅ Maintain proper hierarchy (H1 > H2 > H3)
- ❌ Don't mix more than 2 font families
- ❌ Don't use decorative or script fonts
